# Parking Lot Management System

A modular **Parking Lot Management System developed in C** to manage vehicles, customers, parking records, and user authentication.

The project demonstrates important C programming concepts such as **structures, pointers, dynamic memory allocation, file handling, and modular programming**.

## Features

* 🔐 User authentication
* 🚗 Vehicle entry and exit management
* 👤 Customer information management
* 🅿️ Parking record management
* 💾 File handling for persistent data storage
* 🧩 Modular code structure
* 🧠 Use of structures and pointers
* 📦 Dynamic Memory Allocation (DMA)

## Technologies Used

* **Language:** C
* **Concepts:** Structures, Pointers, Dynamic Memory Allocation, File Handling
* **Compiler:** GCC

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/parking-lot-management-system-c.git
```

### 2. Open the project folder

```bash
cd parking-lot-management-system-c
```

### 3. Compile the program

```bash
gcc main.c auth.c vehicle.c customer.c -o parking
```

### 4. Run the program

**Windows:**

```bash
parking.exe
```

**Linux/macOS:**

```bash
./parking
```
